This appendix states how the results can be reproduced: the environments, the
inputs, the run folders and the script behind every table and figure. Paths are
relative to the project repository \texttt{trucksimulation}.

\section{Environments and Inputs}

Discovery uses ProM Lite~1.4; conformance values use ProM~6.15 (PNetReplayer
6.11.191, ETConformance 6.9.52), run headless on the PNML files exported from
ProM. Soundness is checked with WOFLAN as implemented in PM4Py 2.7.22.3. The
simulation runs in a Python 3.11 environment with ProSiT~1.0.4 and PM4Py 2.7.22.3
(\texttt{envs/prosit104}). The training and test logs are in
\texttt{data/processed/CTB/split13apr\_20261106}, with a manifest that records the
split rule, the counts and the SHA-256 hash of each file. Before discovery, the
logs are checked for missing labels, duplicate order positions, cases in both logs
and chronological order, and they are written to XES with a check that each file
reproduces its log sequence by sequence and is read correctly by OpenXES.

\section{Fitted Models and Simulation Runs}

The fitted ProSiT models are stored as Python pickles: the model of each net in
\texttt{simulation\_e3/runs/hm07orig\_20261115/e3/<net>/prosit\_params.pkl}, and the
retrained components of E4 in \texttt{components/components}. The pickles keep the
complete fitted state, including the training samples stored in the leaves;
exact numerical reproduction uses them together with the recorded environment
and the seeds. All simulation runs of E3 to E5 and the controls are in the same
run folder: \texttt{e3} (main condition and contrasts), \texttt{e3\_noguard} and
\texttt{e3\_simpleguard} (guard ablation), \texttt{e4} (all configurations of E4),
\texttt{netx} (final configuration with the contrast nets), \texttt{stale\_final}
(enabling times reset), \texttt{e5} (scenario runs) and the evaluation folders
\texttt{eval\_*}. Each simulated log is a CSV file per seed; every evaluation
writes its values as CSV next to a summary.
