\subsection{Rule Audit and Exact Repair}
\label{sec:mc_repair}
\begin{hints}
\item How a rule is checked on a model: rule as a small monitor automaton, product with the reachability graph, shortest counterexample.
\item How the repair works: intersect the language of the net with the rule monitors, minimise, encode as a state machine (one place per state, one transition per step). Fully automatic, written as a new PNML file; the original net is untouched.
\item What it guarantees: sound, all observed sequences kept, no other sequences added. Figure: repaired net.
\item Consequence for ProSiT: one token per visit, so stops cannot run in parallel; repeated labels make routing state-dependent.
\end{hints}
